# Appearance

Appearance is one object that sets your app's whole theme: colors, UI scale,
text size, density, corners, shadows, borders and font preferences.

`@nxds/core` turns that object into the theme's CSS. The examples use the
React provider or the Vue plugin you copied in
[Install](/getting-started/install).

## Fields

Color is one setting out of many. UI scale, text size, density, corners,
shadows, border width, type and motion are settings too. "Make this product
denser" is a one-field change, not a refactor.

Every option ships in the stylesheet. The provider applies colors as CSS
variables and `mode` as the `.dark` class. It applies UI scale, text size,
density, corners, shadows and border width as data attributes. Switching an
option needs no rebuild.

| Field                            | Values                                                                                                | Sets                                                                        |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `mode`                           | `'light'`, `'dark'`, `'system'`                                                                       | Light or dark. `system` follows the operating system.                       |
| `brandColor`                     | Any CSS color. Default `#0a0a0a`.                                                                     | The primary color.                                                          |
| `surfaceTone`                    | `'stone'`, `'neutral'`, `'zinc'`, `'slate'`, `'gray'`. Default `'zinc'`.                              | The gray used for backgrounds.                                              |
| `lightContrast` / `darkContrast` | `0` to `100`. Default `50`.                                                                           | How strong text and borders are, separately for each mode.                  |
| `uiScale`                        | `'small'`, `'default'`, `'large'`, `'larger'`. Default `'default'`.                                   | Text, icons, spacing and corners together, from 12px to 18px text.          |
| `textSize`                       | `12` to `16`. Default `14`.                                                                           | Text only. The label text size in px at the Default UI scale.               |
| `density`                        | `'tight'`, `'compact'`, `'default'`, `'comfortable'`, `'relaxed'`, `'spacious'`. Default `'default'`. | Spacing.                                                                    |
| `corners`                        | `'square'`, `'subtle'`, `'smooth'`, `'round'`, `'extra-round'`. Default `'subtle'`.                   | Corner radius.                                                              |
| `elevation`                      | `'flat'`, `'quiet'`, `'soft'`, `'standard'`, `'strong'`. Default `'quiet'`.                           | Shadows.                                                                    |
| `stroke`                         | `'fine'`, `'normal'`, `'strong'`. Default `'normal'`.                                                 | Border width.                                                               |
| `prefs`                          | `NxdsAppearancePrefs`                                                                                 | Fonts, the code font size, reduced motion, pointer cursors, font smoothing. |

Fonts and the code font size apply to nxds components only. Reduced motion,
pointer cursors and font smoothing apply to the whole page. All three are off
until a user turns them on.

## UI scale, text size and density

`uiScale` makes the whole UI larger or smaller and keeps its proportions. Use
it for a user's comfort setting. `textSize` makes only the text larger or
smaller, for a user who wants larger text in a dense layout. `density` changes
only the space around the content, for a denser or a roomier product.

| `uiScale`   | Label text | Icon | Default Button |
| ----------- | ---------- | ---- | -------------- |
| `'small'`   | 12px       | 14px | 36px           |
| `'default'` | 14px       | 16px | 40px           |
| `'large'`   | 16px       | 18px | 44px           |
| `'larger'`  | 18px       | 20px | 50px           |

`textSize` is the label text size at the Default scale. The UI scale
multiplies it, and every text style follows. Each cell is the label text size
a user sees:

| `textSize` | `'small'` | `'default'` | `'large'` | `'larger'` |
| ---------- | --------- | ----------- | --------- | ---------- |
| `12`       | 10px      | 12px        | 14px      | 15px       |
| `13`       | 11px      | 13px        | 15px      | 17px       |
| `14`       | 12px      | 14px        | 16px      | 18px       |
| `15`       | 13px      | 15px        | 17px      | 19px       |
| `16`       | 14px      | 16px        | 18px      | 21px       |

Icons and spacing keep their UI scale size at every text size. A control grows
taller only when its text needs more room. Label a text size picker with the `textSize` value. To show the size a user
sees at the current UI scale, call `textSizePx(textSize, uiScale)` from
`@nxds/core`.

Page widths such as `max-w-lg` grow with the UI scale. Breakpoints do not.

Code text grows with the label text. `prefs.codeFontSize` is its size at the
Default scale and text size. The UI scale and the text size never shrink text
below 8px, and code set smaller keeps its size.

The provider puts `data-ui-scale` and `data-text-size` on `<html>`. If you set
the attributes yourself, put both on the root only, so density and corners
inside it follow its scale.

## Change the theme at runtime

<FrameworkTabs>
<FrameworkPanel framework="react">

Read and update the appearance with `useNxdsAppearance`:

```tsx
// components/mode-button.tsx
'use client';

import { useNxdsAppearance } from '@/components/nxds/components/appearance/provider';

export function ModeButton() {
  const { state, setState } = useNxdsAppearance();

  return (
    <button
      type="button"
      onClick={() =>
        setState((current) => ({
          ...current,
          mode: current.mode === 'dark' ? 'light' : 'dark',
        }))
      }
    >
      {state.mode}
    </button>
  );
}
```

Read and update the appearance with `useNxdsAppearance`:

```vue
<!-- src/components/ModeButton.vue -->
<script setup lang="ts">
import { useNxdsAppearance } from '@/components/appearance';

const { state, setState } = useNxdsAppearance();

function toggle() {
  setState((current) => ({
    ...current,
    mode: current.mode === 'dark' ? 'light' : 'dark',
  }));
}
</script>

<template>
  <button type="button" @click="toggle">{{ state.mode }}</button>
</template>
```

`state` and `resolvedMode` are refs, so the template updates when the theme
changes.

Use `useNxdsAppearance` to build theme controls for your own settings page.
To switch brands, set `brandColor` the same way. nxds builds the new palette
and restyles every component at once, without a rebuild.

## Brand color

`brandColor` sets the primary color. nxds builds the full primary palette from
it, including hover and pressed shades.

```ts
// app/appearance-state.ts
import { DEFAULT_NXDS_APPEARANCE, type NxdsAppearanceState } from '@nxds/core';

export const defaultAppearance = {
  ...DEFAULT_NXDS_APPEARANCE,
  brandColor: '#2563eb',
} satisfies NxdsAppearanceState;
```

In light mode, the button uses your color, with very light colors darkened a
little. In dark mode, dark brand colors get lighter so the button stays
visible. A black brand becomes a white button in dark mode.

To let users pick a brand color, copy the `appearance/brand-color-field`
component:

```tsx
// components/brand-editor.tsx
'use client';

import { DEFAULT_BRAND_COLOR } from '@nxds/core';
import { useState } from 'react';

import { NxdsAppearanceBrandColorField } from '@/components/nxds/components/appearance/brand-color-field/brand-color-field';

export function BrandEditor() {
  const [brandColor, setBrandColor] = useState(DEFAULT_BRAND_COLOR);

  return (
    <NxdsAppearanceBrandColorField
      label="Brand color"
      value={brandColor}
      onChange={setBrandColor}
    />
  );
}
```

The field offers nine presets (Default, Indigo, Blue, Violet, Rose, Orange,
Amber, Green and Teal), a color picker and a hex input. A color that matches no preset shows as
**Custom**.

To build your own picker, `@nxds/core` exports the presets:

| Export                             | Returns                                                |
| ---------------------------------- | ------------------------------------------------------ |
| `BRAND_COLOR_PRESETS`              | The preset list                                        |
| `BASE_TONE_OPTIONS`                | The surface tone list                                  |
| `findBrandColorPreset(brandColor)` | The matching preset, or `undefined` for a custom color |

`findBrandColorPreset` matches any opaque CSS color, such as `#4F46E5`,
`4f46e5` or `rgb(79 70 229)`. A translucent color returns `undefined`.

## Surface tone

`surfaceTone` sets the gray behind your content. Every tone is close to
neutral:

| Tone      | Looks                 |
| --------- | --------------------- |
| `neutral` | Pure gray             |
| `stone`   | Slightly warm         |
| `gray`    | Slightly cool         |
| `zinc`    | Cool, slightly violet |
| `slate`   | Coolest               |

In light mode, pages, cards and popovers stay white for every tone. The tone
shows in hover and pressed states, muted surfaces and dark mode.

## Contrast

`lightContrast` and `darkContrast` set how strong text, borders and hover
states are. Each runs from `0` to `100`, with `50` as the default.

- Raise contrast for stronger text and clearer borders.
- Lower it for a softer look. Text stays readable at `0`.
- Brand and status colors keep their color at every value.

Each mode keeps its own value, so a user can raise contrast in dark mode only.
For the contrast targets behind each value, see
[Color](/foundations/color#contrast-setting).

## Fonts

`prefs.uiFont`, `prefs.headingFont` and `prefs.codeFont` set the
`font-family` stacks for UI text, headings and code.

```ts
// app/appearance-state.ts
import { DEFAULT_NXDS_APPEARANCE, type NxdsAppearanceState } from '@nxds/core';

export const defaultAppearance = {
  ...DEFAULT_NXDS_APPEARANCE,
  prefs: {
    ...DEFAULT_NXDS_APPEARANCE.prefs,
    uiFont:
      '"Inter Variable", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif',
    headingFont: '"Lora Variable", Georgia, serif',
  },
} satisfies NxdsAppearanceState;
```

`headingFont` is `null` by default, so headings use the UI font.

Load a font before you name it. Install its Fontsource package, then import it
in your nxds CSS entry:

```css
/* app/nxds.css */
@import '@fontsource-variable/inter';
@import '@fontsource-variable/lora';
```

[`init --font`](/getting-started/install#optional-set-your-theme) does both
steps, and sets the font in your theme. `FONT_OPTIONS` in `@nxds/core` lists the fonts it offers,
with each font's stack and package:

| Category | Fonts                                                  |
| -------- | ------------------------------------------------------ |
| Sans     | Geist, Inter, Figtree, DM Sans, Manrope, IBM Plex Sans |
| Serif    | Lora, Playfair Display                                 |
| Mono     | Geist Mono, JetBrains Mono                             |

## Icons

nxds components draw their own icons, such as a Select's chevron, from
`lib/icons.ts`. That file draws Phosphor. To use another library, pick it when
you set up:

```bash
npx nxds-cli@latest init --icons lucide
```

| Library      | `--icons`   |
| ------------ | ----------- |
| Phosphor     | `phosphor`  |
| Lucide       | `lucide`    |
| Tabler Icons | `tabler`    |
| HugeIcons    | `hugeicons` |
| Remix Icon   | `remix`     |

Remix Icon uses the Remix Icon License, not MIT. It bars logo use and building
a competing icon set.

Icons you pass to a component, such as a Button's icon, come from any library
you like.

### Line width

Stroked icons draw a 1.75 line in every component, whatever their
`strokeWidth`. Filled icons keep the line their library draws.

| Library      | Draws         | Line in a component |
| ------------ | ------------- | ------------------- |
| Lucide       | Strokes       | 1.75                |
| Tabler Icons | Strokes       | 1.75                |
| HugeIcons    | Strokes       | 1.75                |
| Phosphor     | Filled shapes | Its own             |
| Remix Icon   | Filled shapes | Its own             |

To change the line, set `--nx-icon-stroke`:

```css
/* app/nxds.css, after the imports */
:root {
  --nx-icon-stroke: 1.5;
}
```

To change the line in one component, add `nx:[--nx-icon-stroke:2]` to its
class. A `stroke-*` class doesn't change the line.

## Shuffle

`shuffleNxdsAppearance` returns a random theme built from the curated options.
It picks the brand preset, surface tone, density, corners, elevation, stroke,
UI font and heading font.

```tsx
// components/shuffle-button.tsx
'use client';

import { shuffleNxdsAppearance } from '@nxds/core';

import { useNxdsAppearance } from '@/components/nxds/components/appearance/provider';

export function ShuffleButton() {
  const { setState } = useNxdsAppearance();

  return (
    <button
      type="button"
      onClick={() => setState((current) => shuffleNxdsAppearance(current))}
    >
      Shuffle
    </button>
  );
}
```

Shuffle keeps mode, contrast and the other preferences. Every brand preset
passes the contrast checks on every surface tone.

Shuffle picks from every font in `FONT_OPTIONS`. If your app loads only some
of them, pass those as `fonts`:

```ts
shuffleNxdsAppearance(current, {
  fonts: FONT_OPTIONS.filter((font) => font.value === 'inter'),
});
```

To try it, select **Shuffle** in the theme panel on any docs page, or in the
[Playground](/playground). Then select **Use this theme** to copy the `init`
command that sets it up.

## Save the theme

The provider saves the appearance and restores it before the page paints.
[Install](/getting-started/install#step-3-add-the-appearance-provider) shows the
setup for Next.js, and [Set up Vite](/getting-started/install#set-up-vite) for
Vite.

To change the theme inside one element, see [Overrides](/theming/overrides).
