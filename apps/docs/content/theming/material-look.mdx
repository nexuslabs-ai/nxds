# Material look

A Material-style settings screen, built from nxds parts with your own colors.

<MaterialLookPreview />

## Set your own colors

Create the colors file, with Roboto and the `standard` elevation:

```bash
npx nxds-cli@latest init --own-colors --font roboto --elevation standard
```

Replace its values with Material's palette:

```css
/* app/nxds-colors.css */
@layer theme {
  :root {
    --nx-color-primary-background: #1976d2;
    --nx-color-primary-background-hover: #1565c0;
    --nx-color-primary-foreground: #fff;
    --nx-color-primary-disabled: rgb(0 0 0 / 0.12);
    --nx-color-secondary-background: #9c27b0;
    --nx-color-secondary-background-hover: #7b1fa2;
    --nx-color-secondary-border: rgb(156 39 176 / 0.5);
    --nx-color-error-background: #d32f2f;
    --nx-color-foreground: rgb(0 0 0 / 0.87);
    --nx-color-border-default: rgb(0 0 0 / 0.23);
    /* The other colors */
  }
}
```

The
[full palette](https://github.com/nexuslabs-ai/nxds/blob/main/apps/docs/content/theming/_material-look/material-look.css)
has every color for light and dark. It sets them on a wrapper, so they reach
only the preview on this page. Your app sets them on `:root` and `.dark`.

[Your own colors](/theming/own-colors) covers the colors file.

## Add Material's shadows

Material lifts a card and a button off the page. Redefine the `standard`
elevation in the colors file:

```css
/* app/nxds-colors.css */
@layer theme {
  [data-shadow='standard'],
  .dark[data-shadow='standard'],
  .dark [data-shadow='standard'] {
    --nx-shadow-xs:
      0 2px 1px -1px rgb(0 0 0 / 0.2), 0 1px 1px 0 rgb(0 0 0 / 0.14),
      0 1px 3px 0 rgb(0 0 0 / 0.12);
    --nx-shadow-sm:
      0 3px 1px -2px rgb(0 0 0 / 0.2), 0 2px 2px 0 rgb(0 0 0 / 0.14),
      0 1px 5px 0 rgb(0 0 0 / 0.12);
    --nx-shadow-md:
      0 2px 4px -1px rgb(0 0 0 / 0.2), 0 4px 5px 0 rgb(0 0 0 / 0.14),
      0 1px 10px 0 rgb(0 0 0 / 0.12);
    --nx-shadow-lg:
      0 5px 5px -3px rgb(0 0 0 / 0.2), 0 8px 10px 1px rgb(0 0 0 / 0.14),
      0 3px 14px 2px rgb(0 0 0 / 0.12);
  }
}
```

## Add the parts

```bash
npx nxds-cli@latest add card button switch input label checkbox progress badge
```

Each part needs a different amount of work:

| Part                             | Change                                                      |
| -------------------------------- | ----------------------------------------------------------- |
| Checkbox, Progress, Badge, Label | None. They read the colors you set                          |
| Card                             | A shadow in place of the border                             |
| Button                           | `variant` and `color`, uppercase labels, round icon buttons |
| Switch                           | A new class recipe: a thin track and a raised thumb         |
| Input                            | A new file: the label sits inside the field                 |

## Edit the Card

A Material card has a shadow and no border. Change four class strings in the
Card:

<LookSource look="material" file="card/card.tsx" />

| Material needs                       | Change                                        |
| ------------------------------------ | --------------------------------------------- |
| A shadow, and no border              | `nx:shadow-xs` in place of the border classes |
| 4px corners                          | `nx:rounded-md`                               |
| Tighter padding                      | `nx:p-4` on the header and the content        |
| An action row that fits text buttons | `nx:p-2` on the footer                        |

## Edit the Button

Replace the Button's class recipe:

<LookSource look="material" file="button/button-variants.ts" />

| Material needs                                     | Change in the recipe                                        |
| -------------------------------------------------- | ----------------------------------------------------------- |
| Contained, outlined and text, each in three colors | `variant` and `color`, in place of the single `variant`     |
| Uppercase labels with wider letter spacing         | `nx:uppercase` and a `nx:tracking-*` class                  |
| A shadow that grows on hover and press             | `nx:shadow-sm`, `nx:hover:shadow-md`, `nx:active:shadow-lg` |
| A readable disabled button                         | `nx:disabled:text-disabled-foreground`, and no shadow       |
| 36px tall with 16px side padding                   | `nx:min-h-9` and `nx:px-4`                                  |
| Round icon buttons                                 | `nx:rounded-full` on the icon-only variant                  |

## Rewrite the Switch

A Material thumb is larger than its track, and casts a shadow. Replace the
Switch's two class recipes. The component under them stays as it is:

<LookSource look="material" file="switch/switch.tsx" />

| Material needs                                  | Change in the recipe                           |
| ----------------------------------------------- | ---------------------------------------------- |
| A track thinner than the thumb                  | A 14px track, with a 20px thumb placed over it |
| A raised thumb                                  | `nx:shadow-xs` on the thumb                    |
| The primary color at half strength on the track | `nx:bg-primary-background/50`                  |
| A darker track when the switch is off           | `nx:bg-muted-foreground-subtle`                |

## Rewrite the Input

Material's label sits inside the field and rises into its border. No color or
class change gives the nxds Input that shape, so replace the file:

<LookSource look="material" file="input/input.tsx" />

| Part                        | Job                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------- |
| `<input>`                   | The native field. Its blank placeholder lets CSS tell an empty field from a full one  |
| `<label>`                   | Rests on the text line. Rises to the top edge on focus, or when the field has a value |
| `<fieldset>` and `<legend>` | Draw the outline. The legend opens a gap as wide as the label                         |
| `<p>`                       | Helper or error text, linked to the field with `aria-describedby`                     |

The field keeps no state in JavaScript. Its classes read `:focus` and
`:placeholder-shown`.

If you pass a `placeholder`, the label stays raised, so the two never overlap.

## Use the parts

```tsx
// app/settings/notifications.tsx
import { Button } from '@/components/nxds/components/button/button';
import {
  Card,
  CardContent,
  CardFooter,
  CardHeader,
  CardTitle,
} from '@/components/nxds/components/card/card';
import { Input } from '@/components/nxds/components/input/input';
import { Label } from '@/components/nxds/components/label/label';
import { Switch } from '@/components/nxds/components/switch/switch';

export function Notifications() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Notifications</CardTitle>
      </CardHeader>
      <CardContent className="nx:flex nx:flex-col nx:gap-6">
        <Input label="Send to" type="email" />
        <div className="nx:flex nx:items-center nx:justify-between">
          <Label htmlFor="product-updates">Product updates</Label>
          <Switch id="product-updates" defaultChecked />
        </div>
      </CardContent>
      <CardFooter className="nx:justify-end">
        <Button variant="text">Cancel</Button>
        <Button>Save</Button>
      </CardFooter>
    </Card>
  );
}
```

## What nxds provides

| From nxds           | In this example                                                         |
| ------------------- | ----------------------------------------------------------------------- |
| Light and dark mode | The provider switches `.dark`, and the colors file has a value for each |
| Density             | Every part sizes itself from nxds spacing tokens                        |
| Corners and stroke  | The parts read the nxds radius and border width tokens                  |
| Color names         | Every class reads an nxds color, so one file recolors every part        |
| Behavior            | Switch and Checkbox keep their keyboard and screen reader support       |

The preview on this page follows the page's mode, density and corners. Its
colors come from the palette file, so the brand color in the theme picker
doesn't change it.

The example has no ripple. Material draws its ripple with JavaScript.
