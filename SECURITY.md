# Security policy

## Report a vulnerability

Don't open a public issue for a security problem. Report it privately instead, with GitHub's [Report a vulnerability](https://github.com/nexuslabs-ai/nxds/security/advisories/new) form.

Say what's affected, how to reproduce it, and what an attacker could do with it.

## Supported versions

nxds is pre-1.0, so fixes go into the latest release only. That covers `@nxds/core`, `nxds-cli`, `@nxds/eslint-plugin`, `@nxds/claude-design` and the components `nxds-cli` installs.

## What happens next

We reply within 3 business days. We fix the problem in private and release the fix. Then we publish an advisory that credits you, unless you'd rather stay anonymous.
