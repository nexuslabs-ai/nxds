The shared parts of an editable condition: field, operator, value and removal. ChoiceFilter and NumberRangeFilter use these same parts and add working editors. FilterCondition alone does not select values or filter data.

<Canvas of={FilterConditionStories.Anatomy} />

One compact size follows nxds density. The field, operator, value and remove button share the h-8 height token; there is no size prop. Change density in the toolbar to see them adapt together. Inputs inside an editor retain their own appropriate control size.

Field names identify the condition. The operator and value are separate buttons; each opens its own editor. The final button removes it. This anatomy example demonstrates button callbacks only.

```tsx
import {
  FilterCondition,
  FilterConditionField,
  FilterConditionSegment,
  FilterConditionRemove,
} from '.';

// Connect each callback to your editor or application state.
<FilterCondition>
  <FilterConditionField>Status</FilterConditionField>
  <FilterConditionSegment
    aria-label="Edit status operator: is"
    onClick={openOperator}
  >
    is
  </FilterConditionSegment>
  <FilterConditionSegment
    aria-label="Edit status value: Paid"
    onClick={openValue}
  >
    Paid
  </FilterConditionSegment>
  <FilterConditionRemove onClick={removeCondition}>
    Remove status filter
  </FilterConditionRemove>
</FilterCondition>;
```

## Use a working block

Six copyable blocks build on this anatomy. Each adds its own editor and decides when a change applies.

- [ChoiceFilter](?path=/docs/blocks-filtering-choice-filter-choicefilter--docs): one value from a short list, applied immediately.
- [MultiChoiceFilter](?path=/docs/blocks-filtering-multi-choice-filter-multichoicefilter--docs): several values, applied with Apply.
- [TextFilter](?path=/docs/blocks-filtering-text-filter-textfilter--docs): text a record contains, starts with or equals.
- [NumberComparisonFilter](?path=/docs/blocks-filtering-number-comparison-filter-numbercomparisonfilter--docs): one number compared with a threshold.
- [NumberRangeFilter](?path=/docs/blocks-filtering-number-range-filter-numberrangefilter--docs): a number between a minimum and a maximum.
- [DateRangeFilter](?path=/docs/blocks-filtering-date-range-filter-daterangefilter--docs): a range of calendar days.

## Compose a custom editor

Use these parts directly for an editor the blocks do not provide, such as Location / within / a distance opening a location-and-radius editor. Import the parts from @nxds/react. Supply your own editor, controlled values, open state, validation, and focus after removal. Use FilterChip when editing happens elsewhere and the chip only removes.
