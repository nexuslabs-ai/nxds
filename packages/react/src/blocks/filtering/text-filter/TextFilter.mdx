Filter records whose text contains, equals, does not equal or starts with a value, or is empty or not empty. The text is a draft until you press Apply.

## When to use it

Use it for free-text fields such as names or titles. For a fixed set of values, use ChoiceFilter or MultiChoiceFilter.

## Value and changes

`value` is controlled: pass the current condition and update it in `onChange`. `null` means no filter.

```tsx
type TextCondition =
  | { operator: 'contains' | 'is' | 'isNot' | 'startsWith'; value: string }
  | { operator: 'isEmpty' }
  | { operator: 'isNotEmpty' };
```

- Apply, or Enter in the field, emits the trimmed text. Blank text cannot be applied.
- Changing between text operators keeps the text and emits immediately.
- _Is empty_ and _is not empty_ emit immediately.
- Switching from an empty operator waits for text and Apply.
- Pressing × emits `null`.

The block owns the open editor, the draft and a pending operator. Applying never submits a surrounding form.

## States and dismissal

Cancel, Escape and clicking outside discard the draft; nothing is emitted. Focus returns to the value you edited, to the operator when you backed out of a pending operator, and to Add after you remove the filter. Replacing the value from outside, or disabling the block, closes an unfinished editor without emitting. An open operator menu is not closed when the block is disabled.
