Compare one number: equals, not equals, greater than or less than. The number is a draft until you press Apply.

## When to use it

Use it for a single threshold such as an amount or a count. For a range with both ends, use NumberRangeFilter.

## Value and changes

`value` is controlled: pass the current condition and update it in `onChange`. `null` means no filter.

```tsx
type NumberComparisonCondition =
  | { operator: 'is' | 'isNot' | 'greaterThan' | 'lessThan'; value: number }
  | { operator: 'isEmpty' }
  | { operator: 'isNotEmpty' };
```

- Apply, or Enter in the field, emits a finite number. Zero, negatives and decimals work.
- Optional `lowerBound` and `upperBound` are inclusive; a value outside them cannot be applied. `unit` is display text only.
- Changing between comparison operators keeps the value and emits immediately.
- _Is empty_ and _is not empty_ emit immediately.
- Switching from an empty operator waits for a number and Apply.
- Pressing × emits `null`.

The block owns the open editor, the draft and a pending operator. Bounds changing while the editor is open do not close it; the draft is re-checked against the new bounds.

## States and dismissal

Cancel, Escape and clicking outside discard the draft; nothing is emitted. Focus returns to the value you edited, to the operator when you backed out of a pending operator, and to Add after you remove the filter. Replacing the value from outside, or disabling the block, closes an unfinished editor without emitting. An open operator menu is not closed when the block is disabled.
