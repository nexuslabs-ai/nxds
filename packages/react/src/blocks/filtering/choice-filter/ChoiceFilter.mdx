Filter by one value from a short list. Selecting a value applies it immediately.

## When to use it

Use it for a short list of mutually exclusive options where each choice is cheap to apply. To match several values at once, use MultiChoiceFilter. For a long list, compose a searchable Command menu instead.

## Value and changes

`value` is controlled: pass the current condition and update it in `onChange`. `null` means no filter.

```tsx
type ChoiceCondition =
  | { operator: 'is' | 'isNot'; value: string }
  | { operator: 'isEmpty' }
  | { operator: 'isNotEmpty' };
```

- Selecting a value emits a complete condition immediately and closes the menu.
- Choosing _Any_ or pressing × emits `null`.
- Changing between _is_ and _is not_ keeps the value and emits immediately.
- _Is empty_ and _is not empty_ emit immediately and hide the value.
- Switching from an empty operator to _is_ or _is not_ waits until you choose a value; nothing incomplete is emitted.

The block owns only its open menu and a pending operator. Option IDs are data and labels are display text; IDs must be unique, nonempty strings. ChoiceEditor is also exported for use inside your own DropdownMenuContent.

## States and dismissal

Escape and clicking outside close the menu without a change. Focus returns to the value, to the operator after backing out of a pending operator, and to Add after removal. Replacing the value from outside, or disabling the block, closes the menu. An unknown ID stays visible as “(unavailable)” until you replace or remove it.
