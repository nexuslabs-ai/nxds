Filter by a number between a minimum and a maximum. The range is a draft until you press Apply.

## When to use it

Use it when both ends matter, such as a size or price band. For a single threshold, use NumberComparisonFilter.

## Value and changes

`value` is controlled: pass the current condition and update it in `onChange`. `null` means no filter.

```tsx
type NumberRangeCondition =
  | { operator: 'between'; min: number; max: number }
  | { operator: 'isEmpty' }
  | { operator: 'isNotEmpty' };
```

- Apply, or Enter in a field, emits both ends together. Both are required, finite and ordered; signed decimals work.
- Optional `lowerBound` and `upperBound` limit the range. `unit` is display text only.
- An error appears only when both ends are filled and the range is wrong.
- _Is empty_ and _is not empty_ emit immediately.
- Switching from an empty operator to _is between_ waits for a valid range and Apply.
- Pressing × emits `null`.

The block owns the open editor, the draft and a pending operator.

## States and dismissal

Cancel, Escape and clicking outside discard the draft; nothing is emitted. Focus returns to the value you edited, to the operator when you backed out of a pending operator, and to Add after you remove the filter. Replacing the value from outside, or disabling the block, closes an unfinished editor without emitting. An open operator menu is not closed when the block is disabled.
