Add `@nxds/angular`: nxds components for Angular 22, built on spartan brain and the Angular CDK with the same `nx:` classes and token CSS as `@nxds/react`. Put each component on the element React renders, as `<button nxButton>` or `<div nxCard>`. The first components are Alert, Badge, Button, Card, Dialog, Input, Label, Spinner, Switch and Tabs. `provideNxdsAppearance()` and the `NxdsAppearance` service run the theme engine, like the React provider. Copy the files you need from the docs, as for Vue.
